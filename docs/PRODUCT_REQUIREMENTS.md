# Product Requirements (Summary)

Full specification provided in the implementation brief. This platform supports:

- **Dual scope types:** temporary projects (construction, hospital conversion, IT) and recurring operational budgets (hospital/restaurant monthly and annual).
- **Independent reporting dimensions:** OBS, CBS, WBS, time, control scope, control account.
- **Financial control:** immutable approved budgets, commitments, actual import with allocation, EAC/EV/CPI/SPI, variance explanations.
- **Governance:** roles, scoped assignments, RLS, audit trail, approval workflows.
- **Bilingual UX:** Arabic RTL and English LTR with localization files only.

See [DOMAIN_MODEL.md](./DOMAIN_MODEL.md) and [FINANCIAL_RULES.md](./FINANCIAL_RULES.md).
